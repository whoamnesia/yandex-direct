# astudio-yandex-direct — кампании в Яндекс Директе для Claude Code

[English](README.md) · **Русский**

Автор: **astudio.one** — [astudio.one](https://astudio.one) · Лицензия: MIT · Версия 1.0.0

Плагин делает агента аккуратным специалистом по Яндекс Директу: семантика с минус-словами на трёх уровнях, комбинаторные объявления в действующих лимитах ЕПК, структура кампаний от брифа до черновика, стратегии по объёму данных, аудит кабинета с доказательствами и еженедельные отчёты по приоритетным целям. Лимиты берутся из датированного справочника, цифры считает код, а агент ничего не запускает, не удаляет и не оплачивает.

## Что умеет

- Конвейер «бриф → черновик» с согласованием маркетолога после каждого шага и списком блокеров
- Проверка комбинаторных объявлений: 7 заголовков по 56, 3 текста по 81 и 15 узких знаков, быстрые ссылки, уточнения, ссылки, превосходные степени и правило о русском языке 2026 года
- Проверка ключевых фраз: до 7 слов, операторы, дубли, лимиты минус-слов, минус-слова, которые режут свои же фразы, предложения по кросс-минусовке
- Справочник стратегий: оплата за клики, средняя цена конверсии, оплата за конверсии, ДРР, «Максимум прибыли», обучение и минимальные бюджеты
- Аудит со статусами «да / нет / нет данных / неприменимо», оценкой здоровья и отдельным покрытием данными, без буквенных оценок
- Недельный отчёт из CSV: CTR, CPC, CR, CPA, ДРР, ROMI, MISSING вместо нуля, неделя к неделе, список «3× CPA» на разбор
- Заметки по API Директа v5/v501, Reports, Метрики и Wordstat v2 с правилами безопасности для любого MCP

## Установка

В Claude Code:

```
/plugin marketplace add whoamnesia/yandex-direct
/plugin install astudio-yandex-direct@astudio-yandex-direct
```

Перезапустите Claude Code. Навыки появятся в меню `/` как `astudio-yandex-direct:astudio-yandex-direct` …

Установка на закреплённом коммите (так делает aiocenter.ru): склонируйте репозиторий, перейдите на опубликованный коммит и выполните `/plugin marketplace add ~/.aiocenter/packages/astudio-yandex-direct`.

Другие агенты (Cursor, Codex, Gemini CLI): каждый навык — обычный `skills/<name>/SKILL.md` со справочниками; укажите агенту папку или скопируйте её в правила агента.

## Навыки

| Навык | Что делает |
|---|---|
| `astudio-yandex-direct` | Главный навык: маршрутизация, пять правил, согласования, факты / гипотезы / нет данных |
| `semantics` | Маски, Wordstat, кластеризация, операторы, минус-слова, кросс-минусовка |
| `ad-copy` | Комбинаторные объявления, быстрые ссылки, уточнения, требования закона |
| `campaign-structure` | От брифа до черновика кампании с согласованиями |
| `strategies` | Стратегия по объёму данных, обучение, бюджеты |
| `audit` | Аудит кабинета с доказательствами и покрытием |
| `weekly-report` | Недельный отчёт по приоритетным целям |

## Инструменты

Python 3.9+, только стандартная библиотека. Читают то, что вы им передали, и ничего не записывают, если вы сами не перенаправите вывод.

| Скрипт | Назначение |
|---|---|
| `scripts/ad_check.py` | Проверяет объявления по лимитам ЕПК и правилам текста |
| `scripts/keywords.py` | Проверяет ключевые фразы и минус-слова, предлагает кросс-минусовку |
| `scripts/kpi.py` | Таблица KPI за неделю, сравнение с прошлой, список «3× CPA», покрытие |
